Build a dependency-free browser instrument called Chroma Atlas: a clean-room colour and gradient workstation, not a clone of any existing site. Use plain HTML, CSS, and classic JavaScript so it works from file://. Keep one normalized configuration as the source of truth. Provide five workspaces: Gradient, Colour, Image, Space, and Library. Gradient must support two-to-four fixed colour stops, exact positions, sRGB/linear-sRGB/OKLab/OKLCH interpolation, and linear, radial, angular, blurred-air, nested-square, monochrome, and six ordered-dither treatments. Colour must show exact hex, OKLab/OKLCH values, readable foreground choice, and WCAG contrast. Image must decode a local static PNG/JPEG/WebP without uploading it, enforce 20 MB and 20 megapixel caps, ignore transparent pixels, extract two-to-twelve deterministic dominant colours in OKLab, report proportions, and apply them to the gradient. Space must be an honest interactive Canvas 2D projection of Cartesian OKLab with OKLCH explained as cylindrical coordinates—not a mislabeled Munsell viewer. Library must include original built-in palettes and device-local named favourites with JSON backup/restore, plus a clearly labeled session-only fallback when embedded storage is unavailable. Export the same state as PNG, JPEG, baseline uncompressed RGB TIFF, sampled-stop SVG, progressive CSS, and versioned JSON at explicit dimensions. Separate artifact creation from the visible download gesture. Include keyboard alternatives, reduced motion, empty/loading/error/success states, tests for colour math, dithering, extraction, encoders, and a typed adapter/bridge. Expose named collections to bridge callers, and require single-use in-frame consent before any embedded image-derived export. Credit Japanese Gradients for UI by Nuevo only as the behavioral reference; reuse none of its code, data, assets, copy, or visual design.
